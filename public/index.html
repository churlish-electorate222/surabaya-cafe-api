04

Catatan

  • Setiap cafe memiliki status verified dan gmaps_status. Cafe bertanda Permanently closed di Google Maps otomatis tidak ada di dataset ini.
  • Data diperbarui secara berkali melalui pipeline scraping OpenStreetMap + verifikasi Google Maps otomatis.
  • Field opening_hours, price_range, dan address mungkin kosong jika Google Maps tidak menampilkannya. Data yang kosong bukan berarti cafe tidak ada.
  • Lisensi: MIT. Bebas dipakai untuk proyek apapun.
